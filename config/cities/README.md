# City options

Generated by scripts/build_locations.mjs from country-state-city 3.2.1 (51644 distinct city names in supported countries). The local API loads one country on demand; browsers receive up to 40 matching options. No geocoding request leaves the device. City names alone cannot disambiguate every same-name city or prove remote eligibility.

Source: https://github.com/harpreetkhalsagtbit/country-state-city
